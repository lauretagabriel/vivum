One-line: The 1px rule that separates everything — this system has no shadows and few borders, so dividers do the structural work.

```jsx
<Divider spacing={24} />
<Divider orientation="vertical" spacing={16} />
<Divider tone="fade" />
```

`fade` suits the left edge of long lists; `accent` is amber and counts against the one-accent-per-view rule.
